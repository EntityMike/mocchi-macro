# The mascot is original art, not sprites from the game

Mocchi belongs to Koei Tecmo. The mascot, the footer band, and the icon are drawn for this tool in Mocchi's likeness, as fan tools commonly do, so the art is the repo's own and covered by its MIT license. Sprites taken from the game files would be Koei Tecmo's art in the repo, which the license can't cover.

## Considered Options

- **Sprites taken from the game files.** Rejected, for the reason above.
- **No Mocchi,** such as a plain keyboard icon. Rejected: it loses the character that makes the tool feel like part of the community.
