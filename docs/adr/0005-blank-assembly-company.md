# `AssemblyCompany` stays blank

.NET Framework names the user settings folder after the assembly's company, or after the program when there's none. Left blank, `user.config` goes under `%LOCALAPPDATA%\MocchiMacro\`, a folder an organizer can recognize. The author's name still shows on the .exe, in the copyright, which is the field Explorer displays.

Setting a company in a later version would move the settings folder, so every organizer's saved game and typing rate would go back to their defaults.
