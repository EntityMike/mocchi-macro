# Changelog

What's changed in each release of Mocchi Macro, newest first.

## 1.0.0

The first release.

- Types a search text into the on-screen keyboard of Monster Rancher 1 DX or Monster Rancher 2 DX, picked in a dropdown.
- Works with the game in a window of any size or fullscreen, at any Windows display scaling.
- A hotkey, Ctrl+Alt+Shift+M, brings the tool to the front from any program, ready to type the next search text. It falls back to Ctrl+Shift+F9 or Ctrl+Alt+Shift+F9 if another program has it.
- Stand-ins such as `@` for ○ type the keyboard's symbols.
- Holds the search text to the monster field's 12 characters, and drops characters the keyboard has no key for, with a note saying which.
- The typing rate can be set from 1 to 10 keys per second.
- Remembers the game and the typing rate between runs.
- The mascot shows how typing went, alongside the status line.
- An update notice says when a newer release is out.
- An About box, opened by the "?" button, says what the tool is and who made it, with links to help, support, and the game.
- One .exe, with nothing to install.
